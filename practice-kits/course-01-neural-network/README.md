# 第一课 · 神经网络识别手写数字

最终项目：**从零写出 MLP，并识别 MNIST 手写数字**。这一课从第一次运行 Python 开始，七个文件会在不同小节反复补充。

## 文件顺序

1. `0100_hello.py`：第一次运行 Python；
2. `0101_python_basics.py`：变量、条件、循环和函数；
3. `0102_numpy_practice.py`：数组、shape、reshape 和矩阵乘法；
4. `0103_neuron.py`：权重、偏置、激活与单个神经元；
5. `0104_mlp.py`：MLP、前向传播、损失与反向传播；
6. `0105_train.py`：batch、epoch、训练集与测试集；
7. `0106_predict.py`：读取真实图片并完成预测。

`materials/MNIST.md` 说明数据来源、文件和检查方法，不包含完整实现。

## 自检规则

1. 先在纸上写输入、计算、输出和 shape；
2. 每次只完成网站要求的一个任务；
3. 先打印中间值，再判断问题出在哪里；
4. 成功运行后再查看网页标准答案。
