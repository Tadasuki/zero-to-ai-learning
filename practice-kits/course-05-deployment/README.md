# 部署 AI 小应用 · 练习素材

最终项目：**可分享的预测网页**。本目录有 15 个空白练习和一份可直接读取的小型示例数据。

建议按编号完成；每次写完先运行、再回网页验证，最后才查看答案。

## 文件顺序

- `0500_deployment.py`：训练与推理是两件事
- `0501_deployment.py`：模型文件、配置与版本
- `0502_deployment.py`：先写输入输出契约
- `0503_deployment.py`：校验输入并复用预处理
- `0504_deployment.py`：组成纯净的推理管线
- `0505_deployment.py`：HTTP、JSON 与状态码
- `0506_deployment.py`：实现预测请求处理器
- `0507_deployment.py`：网页需要四种状态
- `0508_deployment.py`：用 fetch 发请求
- `0509_deployment.py`：错误、安全与隐私
- `0510_deployment.py`：性能、缓存与批量
- `0511_deployment.py`：版本、灰度与回滚
- `0512_deployment.py`：测试与健康检查
- `0513_deployment.py`：部署、日志与监控
- `0514_deployment.py`：发布你的 AI 小应用

## 自检规则

1. 每节至少保留一个 `assert`；
2. 在根目录 `EXPERIMENT_LOG.md` 记录结果；
3. 不直接复制标准答案；
4. 最终项目补充 README 和失败案例。
