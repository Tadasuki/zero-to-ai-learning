# CNN：让网络更会看图片 · 练习素材

最终项目：**迷你图案分类器**。本目录有 15 个空白练习和一份可直接读取的小型示例数据。

建议按编号完成；每次写完先运行、再回网页验证，最后才查看答案。

## 文件顺序

- `00_cnn.py`：图片在电脑里是一组数字
- `01_cnn.py`：建立图片数据集与标签
- `02_cnn.py`：可视化与归一化
- `03_cnn.py`：卷积核寻找局部模式
- `04_cnn.py`：亲手实现二维卷积
- `05_cnn.py`：步幅、填充与输出尺寸
- `06_cnn.py`：多卷积核、多通道与特征图
- `07_cnn.py`：ReLU 保留有用响应
- `08_cnn.py`：池化压缩空间
- `09_cnn.py`：追踪一整个 CNN 的形状
- `10_cnn.py`：损失、优化器与训练循环
- `11_cnn.py`：数据增强与过拟合
- `12_cnn.py`：混淆矩阵与错误样本
- `13_cnn.py`：公平比较 MLP 与 CNN
- `14_cnn.py`：完成迷你图片分类器

## 自检规则
