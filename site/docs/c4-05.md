# 完成短评情感分类器

<p class="lesson-lead">最终项目把短评数据整理为训练集和测试集，建立词表，用词袋向量训练二分类器，再接受一条新短评进行预测。</p>

<div class="shape-flow"><span>文本<small>原始短评</small></span><b>→</b><span>清洗分词<small>固定规则</small></span><b>→</b><span>词袋向量<small>固定词表</small></span><b>→</b><span>分类概率<small>Sigmoid</small></span></div>

保存的不只是权重，还包括词表、清洗规则版本和阈值。缺少其中任何一项，部署时都可能无法复现训练结果。

<div class="milestone"><strong>项目验收</strong><label><input type="checkbox"> 词表只来自训练集</label><label><input type="checkbox"> 训练与预测使用相同预处理</label><label><input type="checkbox"> 报告类别分布和测试准确率</label><label><input type="checkbox"> 分析否定句等失败样本</label><label><input type="checkbox"> 能输入自定义短评得到概率</label></div>

<details class="checkpoint"><summary>项目完成后应能讲清哪条主线？</summary><p>文本经过固定预处理变成定长向量，分类器将词语证据加权成分数，再转换为概率并根据阈值输出类别。</p></details>
