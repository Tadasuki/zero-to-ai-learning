# 从分数到概率，再到损失

<p class="lesson-lead">输出层先产生 10 个任意分数。Softmax 把它们变成概率，交叉熵再把预测和正确答案之间的差距变成一个损失值。</p>

## Softmax 做什么？

Softmax 先对每个分数取指数，再除以所有指数之和：

```text
pᵢ = exp(zᵢ) / Σ exp(zⱼ)
```

结果有两个性质：每个概率在 0～1 之间；全部概率之和为 1。为了避免指数过大，代码中通常先减去这一行的最大值，这不会改变最终比例。

## 正确答案怎样表示？

如果标签是 7，正确类别就是概率数组的第 7 号位置。程序不需要把“7”变成文字，只要用它作为索引取出正确概率。

## 交叉熵损失

```text
loss = -log(正确类别的概率)
```

正确概率接近 1 时，损失接近 0；正确概率接近 0 时，损失会很大。损失是训练时的方向标，不是准确率。

<div class="compare-grid"><div><strong>准确率</strong><p>最终猜对了多少张，只看对错。</p></div><div><strong>损失</strong><p>预测概率离正确答案有多远，能提供更细的更新信号。</p></div></div>

<div class="exercise"><strong>本节动手任务</strong><ol><li>给出三个类别分数 `[2.0, 1.0, 0.1]`。</li><li>按公式手算指数、总和和三个概率，可使用计算器。</li><li>检查概率和是否约等于 1。</li><li>假设正确答案是第 0 类，计算 `-log(p0)`。</li><li>再假设正确答案是第 2 类，比较损失。</li></ol></div>

<details class="checkpoint"><summary>自检：置信度 90% 是否等于现实中有 90% 一定正确？</summary><p>不等于。它只是模型内部根据当前参数计算出的概率。模型可能过度自信，也可能遇到与训练数据差异很大的图片。</p></details>
