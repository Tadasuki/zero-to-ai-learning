# API 是网页与模型的约定

<p class="lesson-lead">网页与模型通常运行在不同位置。网页发送请求，服务器接收输入、调用模型，再返回 JSON 响应。</p>

`POST /predict` 表示向预测地址提交数据。成功可返回 200；用户输入错误通常是 400；服务器内部失败是 500。状态码和响应正文都要清楚。

```json
{"label":"正面","confidence":0.91,"model_version":"1.0"}
```

本课网页实验室不真正启动公网服务器，而是先实现等价的 Python 处理函数，理解接口契约后再迁移到 Flask 或 FastAPI。

<div class="exercise"><strong>本节任务</strong><ol><li>实现 handle_predict(payload)。</li><li>缺少 input 时返回明确错误。</li><li>成功时返回固定字段。</li></ol></div>

<details class="checkpoint"><summary>自检：为什么 API 字段不能随便改名？</summary><p>前端代码依赖约定读取字段；任意改名会造成兼容性问题，应通过版本管理协调变化。</p></details>
