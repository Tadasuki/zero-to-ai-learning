# 建立可靠的推理管线

<p class="lesson-lead">一个可靠的 predict_pipeline 不只调用模型，还要拒绝无效输入，并返回网页容易使用的结构化结果。</p>

<div class="shape-flow"><span>校验输入<small>类型、大小、范围</small></span><b>→</b><span>预处理<small>与训练一致</small></span><b>→</b><span>模型推理<small>不更新参数</small></span><b>→</b><span>格式化<small>label + confidence</small></span></div>

错误信息也属于接口设计。不要让用户看到长堆栈；应返回“图片格式不支持”之类可操作的信息，同时在开发日志保留细节。

<div class="exercise"><strong>本节任务</strong><ol><li>校验输入必须是数值列表。</li><li>限制长度和数值范围。</li><li>返回包含 label、confidence、model_version 的字典。</li></ol></div>

<details class="checkpoint"><summary>自检：为什么输入校验必须在模型之前？</summary><p>它能尽早阻止格式错误、超大输入和异常值，避免模型崩溃或浪费资源。</p></details>
