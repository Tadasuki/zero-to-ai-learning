# 用均方误差衡量预测

<p class="lesson-lead">模型需要一个数字告诉它“错了多少”。回归常用均方误差：先求预测与真实值之差，平方，再取平均。</p>

```text
MSE = mean((预测值 - 真实值)²)
```

平方让正负误差不会互相抵消，也让大错误受到更重惩罚。梯度则回答：稍微增大 w 或 b，损失会上升还是下降？

对于 `ŷ=wx+b`，每个样本的误差为 `e=ŷ-y`。平均梯度可以写成 `dw=mean(2ex)`、`db=mean(2e)`，然后执行 `参数 -= 学习率 × 梯度`。

<div class="exercise"><strong>本节任务</strong><ol><li>实现 mse(y_true,y_pred)。</li><li>实现 dw 与 db。</li><li>完成一次参数更新，确认损失没有增大。</li></ol></div>

<details class="checkpoint"><summary>自检：为什么不能只看某一个样本的误差？</summary><p>模型要适用于整组数据。单个样本可能偶然特殊，平均损失才能反映整体预测质量。</p></details>
