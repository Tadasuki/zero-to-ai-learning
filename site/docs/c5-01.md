# 保存模型与版本信息

<p class="lesson-lead">模型文件不只是几组权重。要稳定复现预测，还要保存输入 shape、类别名称、归一化参数、词表和模型版本。</p>

NumPy 项目可用 `np.savez` 保存数组，用 JSON 保存普通配置。加载外部模型文件要谨慎，不执行来源不明的序列化对象。

保存后必须做往返测试：同一输入在保存前与重新加载后应得到相同结果。还要明确版本号，避免网页与旧模型混用。

<div class="exercise"><strong>本节任务</strong><ol><li>把 w、b 保存到 npz。</li><li>把类别名和版本保存为字典。</li><li>加载后比较预测是否一致。</li></ol></div>

<details class="checkpoint"><summary>自检：为什么只保存权重可能不够？</summary><p>预测还依赖网络结构、预处理、类别顺序和阈值；这些不一致时，相同权重也会产生错误含义。</p></details>
