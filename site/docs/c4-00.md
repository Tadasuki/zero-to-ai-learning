# 文本怎样变成分类任务

<p class="lesson-lead">文本分类接收一句或一段文字，输出预先定义的类别，例如正面/负面、体育/科技。模型不能直接计算汉字，第一步是把文字变成数字。</p>

标签必须有清楚边界。同一句“还行吧”可能依赖语境，数据标注并不总是绝对正确。零基础项目先从二分类开始，并承认不确定样本。

<div class="concept-chain"><div><b>原始文本</b><span>人类语言</span></div><i>→</i><div><b>数字向量</b><span>模型可计算</span></div><i>→</i><div><b>类别概率</b><span>情感或主题</span></div></div>

<div class="exercise"><strong>本节任务</strong><ol><li>写出五条短评并标注正面或负面。</li><li>找出一条难以判断的文本。</li><li>打印文本和对应标签。</li></ol></div>

<details class="checkpoint"><summary>自检：模型真的“理解”文字吗？</summary><p>入门模型主要学习词语与标签之间的统计规律。它能完成任务，但不等于拥有与人相同的理解。</p></details>
