# 数据表、特征与标签

<p class="lesson-lead">模型不会直接理解一张表的含义。我们要把每一行当作一个样本，把输入列放进 x，把目标列放进 y。</p>

## 一行就是一次观察

假设记录学习时长与分数：`x=[1,2,3,4]`，`y=[52,61,73,82]`。两组数据必须一一对应，不能把 x 打乱却不同时打乱 y。

数据还要检查：缺失值、单位、异常值和数量级。分钟与小时混用会让规律失真；极端异常样本可能把直线拉偏。

<div class="compare-grid"><div><strong>特征 x</strong><p>预测时能够获得的信息。</p></div><div><strong>标签 y</strong><p>训练时用于纠正模型的真实答案。</p></div></div>

<div class="exercise"><strong>本节任务</strong><ol><li>创建长度相同的 x 和 y 数组。</li><li>检查样本数量是否一致。</li><li>计算 x、y 的平均值并解释含义。</li></ol></div>

<details class="checkpoint"><summary>自检：测试时还能把真实标签交给模型吗？</summary><p>不能。模型只能根据特征产生预测；标签只用来在训练或评估时比较预测是否准确。</p></details>
