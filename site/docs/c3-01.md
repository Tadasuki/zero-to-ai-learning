# 图像张量与颜色通道

<p class="lesson-lead">一张灰度图可以表示为 `(高,宽)`，彩色图通常是 `(高,宽,3)`，三个通道分别存红、绿、蓝的强度。</p>

训练时会同时处理多张图片，因此还要增加 batch 维。不同框架可能使用 `(batch,height,width,channels)` 或 `(batch,channels,height,width)`；代码前先确认约定，不要靠猜。

像素通常从 0～255 归一化到 0～1。shape 正确但通道顺序错误，也会让模型看到完全不同的内容。

<div class="exercise"><strong>本节任务</strong><ol><li>创建一张 4×4 灰度图。</li><li>给它增加 batch 和 channel 维。</li><li>打印每一步 shape，并解释每个数字。</li></ol></div>

<details class="checkpoint"><summary>自检：(32,3,28,28) 表示什么？</summary><p>一次处理 32 张图片，每张有 3 个通道，高和宽都是 28；这里采用通道在前的格式。</p></details>
