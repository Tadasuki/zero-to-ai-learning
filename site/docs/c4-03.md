# 用线性分类器计算情感

<p class="lesson-lead">文本已经变成向量 x 后，可以为每个词学习一个权重：`score = x·w + b`。正面词可能得到正权重，负面词可能得到负权重。</p>

Sigmoid 把任意分数压到 0～1：`p=1/(1+exp(-score))`。p 大不等于模型一定正确，它只表示模型在当前参数下的倾向。

二元交叉熵会惩罚“非常自信但判断错误”的情况。训练仍是损失、梯度、更新的循环。

<div class="exercise"><strong>本节任务</strong><ol><li>实现 sigmoid。</li><li>计算一条词袋向量的正面概率。</li><li>比较 score 为 -2、0、2 时的概率。</li></ol></div>

<details class="checkpoint"><summary>自检：阈值为什么常取 0.5？</summary><p>Sigmoid 在 score=0 时输出 0.5，二分类通常以此为默认边界；实际任务也可根据误报和漏报成本调整。</p></details>
