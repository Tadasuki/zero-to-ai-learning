# 分词、清洗与词表

<p class="lesson-lead">分词把文本拆成可计数的单位。英文可先按空格和标点拆分；中文入门项目可以先按字，或使用给定的简单词表做最长匹配。</p>

清洗不是删除得越多越好。感叹号、否定词“不”和程度词“非常”可能影响情感。训练和预测必须使用同一套清洗规则。

词表把 token 映射到整数编号。没见过的词用 `<UNK>`，不要在测试阶段悄悄扩充词表。

<div class="exercise"><strong>本节任务</strong><ol><li>实现 normalize(text)。</li><li>从训练文本建立不重复词表。</li><li>把一句话转换成 token 列表。</li></ol></div>

<details class="checkpoint"><summary>自检：为什么词表只能从训练集建立？</summary><p>如果使用测试文本建立词表，就提前看到了测试数据的信息，评估结果会被污染。</p></details>
