# 为什么图片需要 CNN

<p class="lesson-lead">把图片拉平成一长串数字会丢掉“谁挨着谁”的空间结构。CNN 保留二维邻域，用同一个小滤波器在整张图上寻找局部特征。</p>

一条边、一个角或一小块纹理只占图片局部。它出现在左上角还是右下角，本质仍是同类特征。卷积通过参数共享，用少量权重反复扫描不同位置。

<div class="concept-chain"><div><b>像素邻域</b><span>局部小区域</span></div><i>→</i><div><b>卷积核</b><span>检测特定模式</span></div><i>→</i><div><b>特征图</b><span>哪里出现了该模式</span></div></div>
