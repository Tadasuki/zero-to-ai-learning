# 完成迷你 CNN 项目

<p class="lesson-lead">最终项目是在 MNIST 或 Fashion-MNIST 上训练一个小型 CNN，并把它与第一课的 MLP 做公平比较。</p>

先固定相同的训练集、测试集和评价指标。记录模型参数量、每轮时间、测试准确率和典型错误图片。不要只比较最高准确率，也要比较成本。

<div class="milestone"><strong>项目验收</strong><label><input type="checkbox"> 输入维度和通道顺序正确</label><label><input type="checkbox"> 能解释卷积核、特征图和池化</label><label><input type="checkbox"> 训练集与测试集严格分开</label><label><input type="checkbox"> 保存模型参数</label><label><input type="checkbox"> 分析至少十个错误样本</label></div>

尝试只改变一个变量：卷积核数量、学习率或是否使用池化。记录变化，再解释为什么可能产生该结果。

<details class="checkpoint"><summary>项目完成后应能讲清哪条主线？</summary><p>像素张量经过可学习卷积核形成特征图，ReLU 保留有效响应，池化压缩空间，分类层根据高级特征输出概率。</p></details>
