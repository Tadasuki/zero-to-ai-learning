# 训练、评估与错误分析

<p class="lesson-lead">文本数据也要先划分训练集与测试集。来自同一用户或同一文章的高度相似文本最好放在同一侧，避免信息泄漏。</p>

准确率回答总体有多少判断正确；混淆矩阵还会区分正面被错判为负面、负面被错判为正面。类别不平衡时，只猜多数类也可能获得高准确率。

错误分析比盲目加训练轮数更重要。否定句、反讽、未知词和过短文本通常是入门模型的薄弱点。

<div class="exercise"><strong>本节任务</strong><ol><li>实现 accuracy。</li><li>统计 TP、TN、FP、FN。</li><li>手工分析五条错误文本并归因。</li></ol></div>

<details class="checkpoint"><summary>自检：90% 准确率一定好吗？</summary><p>不一定。若 90% 样本都是同一类，永远猜多数类就有 90%；还要看类别分布和各类错误。</p></details>
