# 发布并验收 AI 小应用

<p class="lesson-lead">最终项目从前四课选择一个模型，做成别人可以输入数据并得到预测结果的小应用。</p>

部署前先在本地完成端到端测试：有效输入、空输入、错误类型、极端值、连续点击和模型文件缺失。配置通过环境变量提供，不把密钥写进前端或仓库。

<div class="milestone"><strong>发布验收</strong><label><input type="checkbox"> 保存模型与版本信息</label><label><input type="checkbox"> 预处理与训练一致</label><label><input type="checkbox"> API 返回固定 JSON</label><label><input type="checkbox"> 手机端可以完成输入和预测</label><label><input type="checkbox"> 错误状态能恢复</label><label><input type="checkbox"> 页面说明用途、限制与隐私</label></div>

上线后记录失败请求比例和响应时间，但不要收集完成任务不需要的个人数据。模型更新时保留旧版本，以便出现问题时回退。

<details class="checkpoint"><summary>五课结束后你真正掌握了什么？</summary><p>你能把现实问题定义成输入和输出，训练并评估模型，理解图像与文本表示，再把稳定的推理流程交给网页用户使用。</p></details>
