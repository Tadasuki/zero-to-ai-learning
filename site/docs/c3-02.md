# 卷积核怎样扫描图片

<p class="lesson-lead">卷积核是一个很小的权重矩阵。它覆盖图片的一块区域，对应元素相乘再相加，得到特征图中的一个数。</p>

3×3 核从左到右、从上到下移动。步幅 stride 决定每次走几格；padding 在边缘补值，决定输出是否缩小。

```text
输出位置 = sum(图片局部区域 × 卷积核) + 偏置
```

若输入为 4×4、卷积核 2×2、stride=1、无 padding，输出是 3×3。判断 shape 时先数窗口有多少个合法起点。

<details class="checkpoint"><summary>自检：卷积核里的数是谁决定的？</summary><p>训练开始时通常随机初始化；反向传播根据损失计算梯度，逐步把它们调整成能够检测有用特征的权重。</p></details>
