# 词袋向量：先做最简单表示

<p class="lesson-lead">词袋模型为词表中的每个词分配一个位置，记录它在文本中出现多少次。向量长度等于词表大小。</p>

例如词表 `[好,差,电影]`，“好电影好”可表示为 `[2,0,1]`。这种表示简单可解释，但会丢失词序：“我不喜欢”和“我喜欢不”可能拥有相同计数。

可以把计数改为是否出现，也可以除以总词数减轻长文本影响。重要的是训练和预测使用同一词表、同一规则。

<div class="exercise"><strong>本节任务</strong><ol><li>实现 vectorize(tokens,vocab)。</li><li>输出固定长度 NumPy 向量。</li><li>验证未知词不会改变长度。</li></ol></div>

<details class="checkpoint"><summary>自检：为什么两个不同句子可能得到相同词袋向量？</summary><p>词袋只记录词出现的次数，不记录顺序；只要词频相同，向量就相同。</p></details>
