# ReLU 与最大池化

<p class="lesson-lead">卷积产生特征响应，ReLU 把负值截为 0；最大池化则在小窗口中只保留最大响应，缩小特征图。</p>

2×2 最大池化、stride=2 会把 4×4 变成 2×2。它没有需要学习的权重，只执行固定规则。池化降低计算量，并让微小位置变化不至于完全改变表示。

<div class="compare-grid"><div><strong>ReLU</strong><p>引入非线性，shape 通常不变。</p></div><div><strong>Max Pool</strong><p>保留局部最强响应，空间尺寸变小。</p></div></div>

池化会丢失信息，所以不是越多越好。应在保留关键结构与降低计算量之间平衡。

<div class="exercise"><strong>本节任务</strong><ol><li>实现 2×2 最大池化。</li><li>检查 4×4 输入得到 2×2 输出。</li><li>比较平均池化与最大池化的结果。</li></ol></div>

<details class="checkpoint"><summary>自检：池化层有可训练参数吗？</summary><p>普通最大池化没有参数，它只按窗口选择最大值；卷积核才是通过训练学习的参数。</p></details>
