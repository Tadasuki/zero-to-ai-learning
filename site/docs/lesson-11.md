# 导数、梯度与反向传播直觉

<p class="lesson-lead">反向传播不是“把答案倒着输入”。它是在回答：每个参数稍微改变一点，最终损失会怎样变化？</p>

## 从坡度理解导数

站在山坡上，坡度告诉你往右走会升高还是降低、变化有多快。导数就是函数在某一点的局部坡度。

训练想让损失下降，所以沿梯度的反方向移动：

```text
参数 ← 参数 - 学习率 × 梯度
```

学习率控制步长。太大可能越过低点，太小则走得很慢。

## 一个参数怎样影响最终损失

权重先影响加权和，加权和影响激活值，激活值影响输出概率，概率再影响损失。链式法则把这条影响链相乘：

<div class="concept-chain"><div><b>权重 w</b><span>改变 z</span></div><i>→</i><div><b>激活 a</b><span>改变输出</span></div><i>→</i><div><b>概率 p</b><span>改变损失</span></div></div>

反向传播从损失开始，沿这条链倒着计算梯度。前向传播保存中间结果，是因为反向时还会用到它们。

## ReLU 的导数

当 z 大于 0，ReLU 输出等于 z，局部坡度是 1；当 z 小于 0，输出固定为 0，局部坡度是 0。

```text
ReLU'(z) = 1  if z > 0
           0  otherwise
```
