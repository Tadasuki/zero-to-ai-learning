# 训练完成不等于可以使用

<p class="lesson-lead">训练代码面向开发者，会读取数据并不断更新参数；部署后的应用面向用户，只接收一次输入并返回一次预测。</p>

推理流程必须包含与训练一致的预处理、模型参数和后处理。只复制“预测函数”而忘记归一化或词表，是最常见的部署错误。

<div class="compare-grid"><div><strong>训练</strong><p>有标签、计算梯度、更新参数，耗时较长。</p></div><div><strong>推理</strong><p>没有参数更新，只处理用户输入并返回结果。</p></div></div>

<div class="exercise"><strong>本节任务</strong><ol><li>写出应用的一条输入和一条输出。</li><li>列出推理必须复用的预处理。</li><li>实现一个不修改参数的 predict。</li></ol></div>

<details class="checkpoint"><summary>自检：部署时为什么不应该继续训练？</summary><p>普通用户请求需要稳定、快速、可复现；若每次请求都更新参数，模型行为会漂移并产生安全与性能问题。</p></details>
