# 从特征图到类别

<p class="lesson-lead">一个小型 CNN 通常重复“卷积 → ReLU → 池化”，再把高级特征送入分类层。</p>

<div class="shape-flow"><span>图片<small>B×1×28×28</small></span><b>→</b><span>卷积 + ReLU<small>B×8×26×26</small></span><b>→</b><span>池化<small>B×8×13×13</small></span><b>→</b><span>分类<small>B×10</small></span></div>

通道数表示模型学习了多少种滤波器。越靠后的层能组合边缘和纹理，形成更复杂的形状。最后的 10 个分数再通过 Softmax 变成类别概率。

训练流程仍然是 forward、loss、backward、step；变化只是参数的组织形式。调试时逐层打印 shape。

<div class="exercise"><strong>本节任务</strong><ol><li>根据给定输入计算每层输出 shape。</li><li>计算展平后的特征数量。</li><li>解释通道数和类别数的区别。</li></ol></div>

<details class="checkpoint"><summary>自检：卷积层越多一定越好吗？</summary><p>不一定。更深模型计算更多，也更容易过拟合；应根据数据量、任务复杂度和验证结果选择。</p></details>
