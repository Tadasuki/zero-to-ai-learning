# 预测一个连续数值

<p class="lesson-lead">识别数字是在十个类别中做选择；预测明天气温、房价或用电量，则要给出一个可以连续变化的数值。这类任务叫回归。</p>

## 先确定输入和目标

模型看到的已知信息叫特征，例如房屋面积、房龄；希望模型学会预测的正确结果叫标签。训练样本是一对“特征 → 标签”。

<div class="concept-chain"><div><b>特征 x</b><span>模型能看到的信息</span></div><i>→</i><div><b>回归模型</b><span>寻找数值规律</span></div><i>→</i><div><b>预测 ŷ</b><span>连续数值</span></div></div>

分类输出“是哪一类”，回归输出“是多少”。在写代码前，先问：结果是类别还是数值？

<div class="exercise"><strong>本节任务</strong><ol><li>写出三个回归问题和一个分类问题。</li><li>为“根据学习时长预测考试分数”指出特征与标签。</li><li>在实验室里定义一个预测值并打印。</li></ol></div>

<details class="checkpoint"><summary>自检：预测 0～9 中的手写数字为什么不是回归？</summary><p>数字看起来是数值，但任务关心的是十个类别中的哪一类，类别之间也不存在连续距离，因此属于分类。</p></details>
