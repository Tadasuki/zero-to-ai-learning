# 完成第一个预测项目

<p class="lesson-lead">现在把数据、预测、损失、梯度、更新和测试接起来，完成“根据学习时长预测分数”的线性回归项目。</p>

## 项目顺序

<div class="shape-flow"><span>准备 x、y<small>检查单位与缺失</small></span><b>→</b><span>划分数据<small>训练 / 测试</small></span><b>→</b><span>循环更新<small>loss → gradient</small></span><b>→</b><span>最终评估<small>只在最后看测试集</small></span></div>

从 `w=0、b=0` 开始，每轮计算训练预测、MSE、dw、db，再更新参数。记录每 20 轮损失，画不出图也可以打印观察趋势。

<div class="milestone"><strong>项目验收</strong><label><input type="checkbox"> 训练损失总体下降</label><label><input type="checkbox"> 测试集从未参与更新</label><label><input type="checkbox"> 能解释 w 与 b</label><label><input type="checkbox"> 能输入一个新时长得到预测</label><label><input type="checkbox"> 保存实验参数与结果</label></div>

<details class="checkpoint"><summary>项目完成后最重要的主线是什么？</summary><p>数据给出输入与答案，模型产生预测，损失衡量差距，梯度指出调整方向，测试集检查规律能否推广到未见样本。</p></details>
