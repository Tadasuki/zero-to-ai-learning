# 一条直线就是最小模型

<p class="lesson-lead">线性回归用一条直线表达输入与输出的关系：`ŷ = wx + b`。它很简单，却包含神经网络训练的全部基本零件。</p>

## 两个可以学习的参数

`w` 是斜率：x 每增加 1，预测改变多少；`b` 是偏置：x 为 0 时的基础值。给定 x 后，前向计算只需乘法和加法。

<div class="formula-card"><strong>ŷ = w × x + b</strong><span>x 是输入，ŷ 是预测，w 与 b 是训练要调整的参数。</span></div>

如果 `w=8、b=45`，学习 3 小时的预测分数为 69。不同的 w、b 对应不同直线，训练就是寻找更合适的一条。

<div class="exercise"><strong>本节任务</strong><ol><li>写 predict(x,w,b)。</li><li>一次输入一个数，再尝试输入 NumPy 数组。</li><li>改变 w 和 b，观察预测如何变化。</li></ol></div>

<details class="checkpoint"><summary>自检：w 和 b 分别控制直线的什么？</summary><p>w 控制倾斜程度和方向，b 控制整条直线在纵轴方向的位置。</p></details>
